# One Last Turn Concerns

[C] Demo integrity: the judge flow must use two real Minds work assignments across separate processes with no scripted substitution.
[C] Authority and privacy: deterministic application code must own authorization, one-turn consumption, and redaction; the Mind must not decide access or expose private boundary text.
[I] Provider reliability: timeout, refusal, malformed output, ambiguous send, or Cognition exhaustion must remain visible failures.
[I] Deadline scope: the build must remain the approved thin vertical slice and exclude the frozen full-app scope.
[A] Polish: visual finish supports the proof but cannot displace the cross-process hero flow.
